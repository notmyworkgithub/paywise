# PAY-102 — Export the payment ledger as CSV

Finance asks for a spreadsheet every month and someone builds it by hand.

## Acceptance criteria
- A function returns the ledger as CSV text: vendor, amount, status, approver.
- Amounts are rendered in whole pounds/dollars, not cents.
- An empty ledger returns just the header row.
- Add tests covering the empty case and a populated case. All existing tests must still pass.
