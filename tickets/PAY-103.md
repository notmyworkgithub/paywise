# PAY-103 — Flag duplicate payments before they are submitted

We have paid the same invoice twice more than once this year.

## Acceptance criteria
- A function detects whether a proposed payment duplicates one already in the ledger
  (same vendor and same amount within the last 30 days).
- Duplicates are flagged, never silently blocked — the caller decides.
- Add tests to `tests/test_payments.py`. All existing tests must still pass.
