# PAY-101 — Add a payment reference to every vendor payment

Finance cannot reconcile payments against bank statements without a stable reference.

## Acceptance criteria
- Every `Payment` carries a `reference` string.
- A helper generates one as `PW-<vendor initials>-<6 digits>`, stable for the same inputs.
- Reject a payment whose reference is empty or malformed.
- Add tests to `tests/test_payments.py`. All existing tests must still pass.
